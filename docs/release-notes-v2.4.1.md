## v2.4.1: tree stages

- **🌳 Skill tree: tree stages, like Path of Building.** If your PoB build has several trees
  (e.g. "Level 30", "Level 70", "Endgame"), pick one from the menu at the top left of the
  Skill tree view. The tree active in PoB opens first and is marked. A character comparison
  carries over when you switch, so you can check your character against the stage you're at.
- Builds whose trees are saved in Path of Building's short form are now read correctly (one
  tree could hide the next).
