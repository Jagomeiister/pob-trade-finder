## v2.5.19: patch notes in the app

- **Settings → Patch notes** lists what every release brought, newest first. The newest is
  open; click any release to open or close it, and **Show older releases** lists the rest.
  - The version you have is marked **installed**, and when a newer one is out it says so at
    the top.
  - Each release ships its own notes, so the list is always up to date after an update.
- **Find a setting** skips the patch notes, so it still finds only settings.
