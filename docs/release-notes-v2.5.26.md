## v2.5.26: Threads planner, lighter in-game windows, fixes

**Threads planner** (3.30)

- On the Threads and Shaped Regions, Atlas and Scarabs sheets, and in the in-game Tools tab:
  the ten Threads with live prices, up to 8 per map, free Threads from a Shaped Region (shown,
  not charged), Unwavering Vision (one Thread type, +2 past the cap), and the cost per map and
  per hour. What the patch notes leave open is said as such.

**Lighter in-game windows**

- Each in-game window loads only the data it uses: 5.3 MB at launch instead of 23.5 MB. The
  trade request windows and the icon load almost nothing.

**Fixes**

- **Search text**: avoiding two common T17 map mods (e.g. "Buffs on Players expire faster")
  no longer also drops every map with More Threads.
- **Item matching**: mods with the 3.30 wording ("Allies within 5 metres gain 2% …") fill the
  right minimum (2, not an average with the 5). Refresh trade data keeps matching items saved
  in Path of Building before 3.30.
- **Build stages**: an empty skill set in PoB no longer takes the next set's gems; PoB's
  loadout tags ("Endgame {3}") pair gear, gems and tree; the stage shown is always the stage
  marked; a saved build is named after PoB's own main skill.
- **Build guides window**: a guide page can no longer open browser tabs without your click;
  the forum index opens; the window's place and size are kept even when it was closed while
  minimised; it can't keep the app running after you quit.
