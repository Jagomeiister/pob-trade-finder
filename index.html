👋 Welcome to PoB Trade Finder
  1. Paste a build: in Path of Building, use Import/Export Build → Generate → Copy, then paste the code (or a pobb.in link) below.
  2. Shop it: every slot becomes a card with the build's mods pre-filled. Use Search on trade site, or Check price to see listings here.
  3. Find upgrades: load your character to see what each slot is missing, then tick ⬆ Upgrades only.
  4. Jewels: the ⏳ Timeless jewels tab finds the best seed for your sockets; 💎 Jewel finder ranks jewel mods for your build.
  5. In game: hover an item and press Ctrl+D to price it (⚙ settings to change the key).

How it works: each mod on the build's gear is matched to the official trade-site stat database (bundled from GGG's /api/trade/data/stats). Tick the mods that matter, set minimum rolls (defaults to 80% of the build's roll), and hit Search on trade site. "All but one" match mode finds items missing any single mod — usually where upgrades hide. Bench-crafted mods start unticked (you'll re-craft them). Uniques are searched by name. In the desktop app, Check price shows live listings without leaving the tool.
